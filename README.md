# DPMP redesign

Hlavní opravy oproti V4:

- pevně definované výšky desktopových sekcí, takže přepínání obsahu neposouvá zbytek stránky,
- sjednocené výšky řádků a sloupců,
- menší a proporčně správnější logo v headeru i footeru,
- odstraněné pomocné / generické popisky typu „Mapa vozidel“, „Chytré parkování“,
- odstraněné náhodné seznamy pracovních pozic v boxu Kariéra,
- odstraněné marketingové a výplňové texty,
- stejné vizuální tempo v jednotlivých částech,
- užší obsahová šířka a realističtější typografické měřítko,
- žádné rounded cards, gradienty, stat countery, hero slogany ani SaaS prvky.

Použito:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Open Sans
- vanilla JavaScript

V6:

- desktop obsah rozšířen na 1280 px,
- základní písmo 16 px,
- header zvětšen na 92 px a logo na 158 px,
- navigace 14 px,
- formulářová pole 46 px / 15 px text,
- názvy a odkazy v sekcích zvětšeny přibližně o 15–25 %,
- horní dopravní sekce, Aktuálně, Cestování MHD, sekundární sekce i footer mají stále pevnou desktopovou výšku,
- mobilní a tabletové breakpointy zůstávají fluidní.
